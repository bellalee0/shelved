새 사건·업로드 상태

원문이 없는 최초 제작 화면

새 초안을 만들었습니다. 소설 원문 .txt 파일을 먼저 업로드하세요. 채팅 이력과 메모장은 비어 있으며 원문 등록 전 제작 메시지 전송은 비활성화됩니다.

원문 파일을 고르면 업로드 중 → 성공 시 파일명·문자 수·업로드 시각 표시 → 첫 메시지 입력을 활성화합니다.

원문·표지 업로드 중 또는 실패

원문은 .txt, 표지는 서버가 허용하는 이미지 형식·크기만 접수합니다. 실제 한도는 구현 설정과 API 계약을 따릅니다.

업로드 중: 중복 업로드 비활성화. 실패: 이유와 재시도 표시, 기존 파일 유지. 성공: 새 파일 정보·표지 미리보기 갱신.

원문 입력량을 맞출 수 없으면 원인과 분할 처리 필요성을 알립니다. 원문을 조용히 잘라 보내지 않습니다.

위 상태는 기존 사건 생성·원문 업로드·표지 업로드 응답을 사용하며 추가 API는 요구하지 않습니다.
